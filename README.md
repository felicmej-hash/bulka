# Булочка — сайт

Статический сайт (HTML/CSS/JS, без сборки) для бренда гипоаллергенных детских игрушек «Булочка».

Страницы: `index.html` (Главная), `about.html` (О нас), `toys.html` (Игрушки).

## Автодеплой на reg.ru

При каждом пуше в ветку `main` (а также вручную, кнопкой) GitHub Actions
заливает файлы сайта по FTP на хостинг reg.ru.
Workflow: `.github/workflows/deploy.yml`.

### Шаг 1. Купи домен и хостинг на reg.ru

Оформи хостинг (подойдёт самый простой тариф с поддержкой FTP) и домен.
После оплаты в личном кабинете reg.ru найди раздел **FTP-доступ** (обычно
в настройках хостинга) — там будут:

- адрес FTP-сервера (например `ftp.твой-домен.ru` или IP-адрес)
- имя пользователя FTP
- пароль
- рабочая директория сайта (обычно `/public_html/` или `/www/твой-домен.ru/`)

### Шаг 2. Добавь эти данные в секреты GitHub-репозитория

В репозитории на GitHub: **Settings → Secrets and variables → Actions →
New repository secret**. Добавь четыре секрета:

| Имя секрета       | Значение                                    |
|--------------------|----------------------------------------------|
| `FTP_SERVER`       | адрес FTP-сервера с reg.ru                   |
| `FTP_USERNAME`     | имя пользователя FTP                         |
| `FTP_PASSWORD`     | пароль FTP                                   |
| `FTP_SERVER_DIR`   | папка на хостинге, куда заливать сайт (например `/public_html/`) |

### Шаг 3. Запусти деплой

- **Автоматически** — просто запушь изменения в ветку `main`, деплой
  запустится сам.
- **Вручную** — во вкладке **Actions** репозитория выбери workflow
  «Deploy to reg.ru» → **Run workflow** (кнопка).

Прогресс и логи деплоя видны там же, во вкладке Actions.

### Если что-то не заливается

- Проверь, что в reg.ru у хостинга включён именно **FTP** (иногда нужно
  отдельно включить FTP-доступ в панели управления).
- Если reg.ru требует обычный FTP без шифрования — в
  `.github/workflows/deploy.yml` замени `protocol: ftps` на
  `protocol: ftp`.
- Убедись, что `FTP_SERVER_DIR` указывает на корневую папку сайта, а не
  на домашнюю папку аккаунта.
