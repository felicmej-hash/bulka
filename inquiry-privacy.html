Политика обработки заявок

Оператор — ООО «Кравцовы», ИНН 9102309556. Для вопросов об обработке данных: Sofia.kravtsova.05@mail.ru.

Какие данные нужны

Имя, выбранный контакт (номер телефона или электронная почта), игрушка, количество и комментарий, если вы его добавили. Указывайте только свои контактные данные. Не добавляйте в комментарий сведения о здоровье, документы или данные других людей.

Для чего они используются

Для регистрации заявки и ответа по выбранному контакту. Отправка заявки не включает подписку на рассылку.

Как хранятся данные

Заявки сохраняются в закрытом файле на сервере сайта. Этот файл доступен через панель хостинга. Данные используются, пока это необходимо для ответа по заявке, и подлежат удалению после обработки или отзыва согласия при отсутствии других законных оснований для хранения.

Как обратиться к оператору

Чтобы запросить сведения о данных, исправить их или отозвать согласие, напишите на адрес выше и укажите контакт, оставленный в заявке.
